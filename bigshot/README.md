# ビッグショット

アレックス・ランドルフのボードゲーム「ビッグショット (Big Shot)」をブラウザで遊べるようにした、単一HTMLファイルのアプリです。

- 4人対戦（あなた + CPU 3名）
- 外部依存なし。`index.html` を開くだけで動作します
- CPU は所有権の確率を厳密に数え上げて競り値を決める

## 遊ぶ

`bigshot/index.html` をブラウザで開くだけです。

## ゲームの骨格

18回の競りで街を分け合います。**このゲームに収入はありません。**
金を使うことはそのまま得点を減らすことなので、「いくらまで出すか」がそのまま「何点ぶんの価値か」になります。

| | |
|---|---|
| 街区 | 11区画（9〜21）＋公園2つ＝13エリア。各エリアに7個までキューブが置ける |
| キューブ | 4色 × 18個 = 72個。18のオークションマスへ4個ずつ配られる |
| 手番 | ①ダイスでマーカーを進める ②止まったマスの4個を競る ③落札者が4個を配置する |
| 所有権 | 最多色が獲る。ただし**同数の色はすべて無効**。3/3/1 なら 1個の色が持っていく |
| 公園 | 公園に隣接する3区画には ×2 の印。その公園を持つ人はその区画が2倍になる |
| 借用書 | 1回の競りにつき1枚まで。1枚目 +9、2枚目 +8…どれも決算で −10 |
| 決算 | 残金 ＋ 土地の価値 − 借用書×10 |

このゲームの肝は**③配置**です。落札した4個には相手の色も混ざっていて、
それも落札者が置きます。相手の色をどこへ捨てるか、
どの区画をわざと同数にして無効化するかが実質の勝負どころになります。

## CPU について

学習は使っていません。かわりに、**所有権の確率を厳密に計算**しています。

区画の状態は「4色の個数、合計7以下」の330通りしかないので、
残りの枠が無作為に埋まると仮定したときの各色の所有確率を、
起動時に多項分布で全部数え上げて表にしておきます（`PROB_TAB`）。
同数無効のルールもこの数え上げの中で処理されるので、
「3個並べても相手に3個合わせられれば0になる」ことが確率にそのまま出ます。

盤面の評価はこの確率で土地の価値を按分するだけです。あとは

- **配置** ── 4個を1個ずつ、残りのキューブ×空き区画を総当りして評価が最大になる場所へ置く
- **競り** ── 「自分が置けた場合」と「誰かに置かれた場合」の評価差がそのまま上限入札額。
  金1＝得点1 なので、点数がそのまま金額になる
- **借金** ── n枚目の借用書の実質負担はちょうど n 点。それを上回る値打ちがあるときだけ切る

最初は所有確率を「置いた数が多いほど有利」という当てずっぽうで近似していましたが、
それだと**空き区画に1個置いただけで勝率43%と見積もってしまい**、序盤に全財産を注ぎ込んで
借金まみれで沈みました（乱択相手に勝率0.43、乱択3人に囲まれると0.59で乱択のほうが勝つ）。
数え上げに替えたところ 0.43 → 0.98 になりました。

### 強さ

4人ゲームなので**互角なら勝率 0.250** です。席順は1局ごとに回しています（各200局）。

| 対戦 | 勝率 |
|---|---|
| **AI 1人 vs 素人筋 3人** | **0.855** |
| AI 1人 vs 浪費家 3人 | 0.995 |
| AI 1人 vs 乱択 3人 | 1.000 |
| 素人筋 1人 vs AI 3人 | 0.055 |
| 乱択 1人 vs AI 3人 | 0.040 |

「素人筋」は自分の色を高い区画へ、相手の色を安い区画へ捨てるだけの相手です。
つまり**相手の色の置き方を考えていない**打ち手で、それを 0.855 で上回ります。
乱択と浪費家はほぼ全勝なので、下限の確認にしかなりません。

AI 4人（全員同じ方策）を600局まわしたときの席別勝率は 0.217 / 0.233 / 0.265 / 0.265 で、
席順による偏りはありません。18回は4で割り切れないので、
手番（＝その競りで最後に入札する席）が5回まわる席と4回の席が出ますが、実測には響いていません。

入札を渋る係数（`THRIFT`）は 0.5〜1.5 を総当りで戦わせて決めました。
0.7〜1.0 はほぼ横ばい（勝率 .24〜.29）で、0.6以下と1.1以上ではっきり落ちます。
その平らな帯の内側の 0.88 を採っています。

AI 4人で300局まわしたときの手触り:

```
落札額     平均 6.3　最高 21　無償 0%
借用書     1人あたり 3.1 枚
決算       残金 4.6　土地 43.6　合計 17.6
所有者なし 1局あたり 1.6 エリア / 13
```

借金が前提のゲームであること、同数無効で毎局1〜2エリアが誰のものにもならないことが、
そのまま数字に出ています。

## 検査

Node.js だけで動きます（外部パッケージ不要）。

```sh
node test/selftest.js   # ルールと不変条件の検査、強さの実測
node test/stats.js 300  # AI同士で回してゲームの手触りを見る
```

`test/harness.js` は `index.html` のロジック区画（`ENGINE_START`〜`ENGINE_END`、
`AI_START`〜`AI_END`）を**そのまま切り出して** Node で実行します。
ブラウザで動くコードと検査するコードがずれません。

## ルールの出典について

公式ルールブックのPDFにはこの環境から到達できず（社外への通信が遮断されている）、
**二次情報（販売サイト・レビュー記事・ゲーム紹介の要約）を突き合わせて再構成**しています。
次の点は複数の情報源で一致が取れています。

- キューブ72個（4色×18）、13エリア、区画の価値 9〜21、一部に ×2
- オークションマス18か所に4個ずつ、初期資金10
- 1エリア7個で締め切り、同数の色は無効（3/3/1 なら1個の色が獲る）
- 決着した区画は勝者のキューブを1個残して他の6個を取り除き、売却済みマーカーを置く
- 借用書は1ラウンド1枚、9・8・7…と減り、どれも決算で −10
- ダイスでマーカーを進め、止まったマスの4個を競る。手番の左隣から、降りたら以降参加できない
- 18回目の競りのあと、未決着の区画も最多色のものになる
- 決算は 残金 ＋ 土地 − 借金

いっぽう次の点は**裏が取れておらず、こちらで筋の通る形に決めたもの**です。

- **街区の配置と、9〜21のうちどの11個を使うか。** ここでは 9,10,11,12,13,14,16,17,18,20,21（合計161点）とし、
  低額の6区画を2つの公園に3つずつ隣接させています（`AREAS`）
- **マーカーが売却済みのマスを飛ばして進むこと**
- **公園の ×2 の効き方。** 「その公園を持っている人の、隣接する ×2 区画が2倍になる」と解釈しています

盤面は `index.html` 冒頭の `AREAS` を書き換えるだけで差し替えられます。
正確なルールブックが手元にある場合は、そこを直せば済むようにしてあります。
