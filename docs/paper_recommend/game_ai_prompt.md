## 設計の根拠（実測）

### 密度の実測（2026-07-29 実施）
直近2週間（7/14-7/28）で該当キーワードを回した結果、関連論文は6件、うち直接関連が3〜4件。
→ **週2〜4件**と見積もり、週1回・下限2件の設計にした。

参考として拾えた具体例:
- `2607.23049` On the Power of Deception in Repeated Games — 一定期間わざと特定の振る舞いをして相手の予測を形成し突く。ハイソサエティの読み合いに直結
- `2607.21856` LeAct: Learning to Reason from Expert Actions — 熟練者行動からの蒸留。先読み蒸留の失敗と関連
- `2607.24219` Algorithms for Equilibria in Concurrent Stopping Games — N人均衡
- `2607.24610` CAP-DO: Certified Double-Oracle Solving for Zero-Sum Games
- `2607.19928` Continuous-Time RL for N-Player Stochastic Differential Games
- `2607.14357` When Is Delegated Play Truthful?

### LLM事後学習による汚染（実測）
`self-play` で検索した上位はこうなった:
- Skill Self-Play: Pushing the Frontier of LLM Capability（49票）
- AREX: Recursively Self-Improving Agent for Deep Research（82票）
- From RLVR to RLSVR

cs.LG の50件サンプルでもRL関連6件中3件がGRPO系だった。
→ **除外規定を最重要項目として明文化**した。

## 未解決・要観察

### 1. 密度の見積もりがサンプル1回のみ
週2〜4件は2週間分の観測に基づく。数回走らせて実績を積む必要がある。
下限2件が妥当かは実行記録を見て判断する。

### 2. 適用可能性の判定精度
「1手6ms・素のJS推論・int8で20KB」に載るかの判定は、抄録だけでは
つかない場合が多いと予想される。判定が外れた場合は Interest に
反映してもらい、傾向を学習させる。

### 3. arXiv の列挙不能（金融トラックと共通）
`/list/*/recent` は古いキャッシュを返し、`export.arxiv.org/api/query`
は robots.txt でブロックされる。キーワード検索に依存する構造は
このトラックでも同じ。

### 4. 会議論文の扱いが未定義
このドメインは NeurIPS / ICML / ICLR / AAMAS / IJCAI の比重が大きい。
arXiv preprint に出ないものをどう拾うかは未検討。

## 運用メモ

- 実行は Routine による**完全自動**。日曜 06:50 JST（＝土曜 21:50 UTC）に起動する。
  手動の指示出しは不要。停止・時刻変更・プロンプト改訂の手順は `README.md` を参照
- 金融トラック（水曜・土曜）とは別スケジュール。プロンプトもDBも共有しない
- リポジトリの実装が変わったら【対象プロジェクトの構成】を更新する。
  ここが適用可能性判定の唯一の基準なので、古いままだと判定がずれる
- `Interest` を「興味あり／興味なし」で埋めることが学習ループの唯一の入力
